# Бабка против зомби! — прототип

Tower defense в духе PvZ: длинная улица, 2–6 рядов, зомби-коты выходят из дверей домов. Бабка-кошатница защищает своих котов гаджетами.

Запуск: открыть `index.html` в браузере.

## Правила дизайна
- Враг идёт по рядам: путь предсказуем.
- У защиты одно действие, у врага одна слабость.
- Каждый сюрприз предупреждается заранее (❗ за 4 сек).
- Уровни ручные, каждый даёт одну новинку.
- Ничего противного, мультяшно.

## Правило анимации
Покадрово (атласы) — только персонажи и механизмы, где важно движение: коты-зомби, кот в колесе, позже мячемёт.
Всё остальное оживляется кодом: скейл (сквош/стретч, «дыхание», отдача, появление), поворот и скос (ветер у деревьев и травы), сплющивание монет при вращении.

## Сцена и меню (код)
- `src/street.js` — улица: далёкий город (2 слоя параллакса), крупные дома вдоль тротуара, тротуары, фонари, передний план из плоских крыш с подворотнями. Перед домами нет кустов и заборов: живая изгородь только у бабкиного газона.
- `src/menu.js` — главное меню по структуре PvZ: пункты меню — предметы сцены (когтеточка с плитами «Играть / Уровни / Огород», висячая табличка с прогрессом, книга-альманах, таблички «Настройки / Заставка»). Невидимые кнопки лежат поверх предметов.
- Интерфейс боя рисуется в экранных координатах и не растёт при зуме камеры; верхняя панель компактная.

## Нужно от арта (Кодекс) — полный список в ASSETS-CHECKLIST.md
Меню ждёт здоровых котов — код подхватит их автоматически по ключам, пока их нет, котов в меню нет (старые кодовые коты убраны):
- `cat-sleep` — свернувшийся спящий кот, вид сбоку, для верхней плиты когтеточки.
- `cat-sit` — сидящий кот анфас/3/4, для подножия когтеточки.
- `cat-loaf` — кот «буханкой» на траве.
Стиль как у остального пака (толстый неровный контур, приглушённая палитра), прозрачный фон, без покадровой анимации.
