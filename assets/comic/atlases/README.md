# Ненарезанные исходные паки

По просьбе пользователя загружены оригинальные PNG целиком. Часть ранее нарезанных спрайтов обрезана; эти исходники предназначены для повторной аккуратной нарезки Claude.

Не делить строго по равной сетке: генерация иногда выходит за границы условных ячеек. Проверять каждый объект целиком, включая уши, хвосты, провода, трубы, двери и пороги. Отдельные объекты обрезать по фактическим границам прозрачности с запасом; не захватывать соседние объекты. После нарезки обновить manifest.json и door для домов, затем встроенный пак и игру.

Файл index.json содержит предполагаемый порядок ключей слева направо, сверху вниз. Это список объектов, а не точные координаты разрезов.

Одобренные нижние дома: front-family-1 — продуктовый, жилой, мастерская, гараж; front-family-2 — аптека с плоской крышей, пекарня, рыбная лавка, цветочный со стеклянной крышей. Не использовать отклонённые прежние варианты с одинаковыми арочными воротами и наклонённой перспективой.

Новых покадровых вариантов нет. garden-stages — статичные стадии роста. menu-cattree и zombie-boss — отдельные оригиналы.
