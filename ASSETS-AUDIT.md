# Нарезка ассетов (14.10.2026)

Нарезку Кодекса заменил своей из целых паков `assets/comic/atlases/` (Claude).

Как резал: объекты по прозрачности целиком (хвосты, провода, капли, искры прицепляются к своему объекту); если два объекта в паке касаются, они разделяются извилистым швом по щели между ними, а не прямой линией. Каждый ассет — холст 512×512, объект по центру, поля ≥ 24 px. Границы и центры дверей в `manifest.json` пересчитаны.

- Двери: у открытых версий домов — центр тёмного проёма (найден автоматически), у закрытых — та же точка относительно дома.
- Порядок в `menu-garden-props.png` в index.json был сдвинут: исправлено (`menu-sign`, `menu-almanac`, `menu-stake-sign`, `menu-slab`).
- Синонимы: `kitten-thief` = `zombie-thief`, `prop-lamp` = `prop-lamp-tall`.
- Старые дома с острыми крышами (`building-*`) убраны — сверху и снизу дороги стоят новые `front-house-1..8`, нижние повёрнуты фасадом к дороге.

Не перерезаны (нет в паках, старые): `prop-car`, `prop-tree`, `prop-bench`, `prop-mailbox`, `zombie-walk-*`, `wheel-run-*` — у них есть обрезы по краю холста.
